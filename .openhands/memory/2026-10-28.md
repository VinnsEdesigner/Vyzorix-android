## The gate was broken (two separate bugs)
1. `scripts/deadcode_gate.py` KOTLIN_DECL/CPP_FUNC were anchored `^` (column 0), so
   *every indented class member was invisible* — the gate reported "clean" over a
   whole library. Also `\s*` between tokens crossed newlines, so a declaration's match
   started on an earlier blank line and the self-reference exclusion (by line number)
   hid genuinely-unreachable public fns. Fixed: `^[ \t]*`, `[ \t]` not `\s`, line from
   the name's own offset. strip_kotlin/strip_cpp now blank with spaces preserving
   newlines (offsets/line numbers stay true). JNI_SYMBOL no longer needs the paren on
   the same line (split JNIEXPORT entry points were false-orphaned). Added
   FRAMEWORK_CALLBACKS + manifest scan so components/callbacks aren't flagged. Added
   interpolation counting (`$name` lives in a literal that strip_kotlin blanks). Added
   `kotlin-test-only-decl` allowlist support.
2. `detekt.yml` had TWO top-level `style:` keys -> detekt aborts
   ("found duplicate key style"). Merged. `./gradlew gate` was red on this alone.

## Build 2 (doc/BUILD_2_CONTRACT.md) — what was actually wrong
- **Socket namespace (the contract's own §2.2 requirement was not met).** `LocalServerSocket(String)`
  binds the ABSTRACT namespace; there is NO public Java API to bind a *filesystem* listening
  socket (only String=abstract and FileDescriptor=already-bound). Added native
  `BindListenSocket` (socket/bind/chmod 0600/listen) + JNI `bindListenSocket`, wrapped via
  `ParcelFileDescriptor.adoptFd(fd)` -> `LocalServerSocket(owner.fileDescriptor)`. Load-bearing:
  without it proot could not reach the bridge at all.
- Auth deadline was only checked when a frame arrived -> a silent client held a slot forever.
  Fixed with `socket.soTimeout` (5s pre-auth, 0 after).
- `pushPtyOutput` broadcast every channel to EVERY connection -> cross-operator terminal leak.
  Now scoped to connections whose token owns the sessionId.
- `onDestroy` never closed sessions -> fd leak. Now closes every session and awaits readers.
- Unbounded outbox -> now a bounded LinkedBlockingQueue; full queue drops the connection.
- `PtyReader.reap` could throw InterruptedException and skip the stop-signal (awaitStopped
  would time out). Now caught; exit callback added.
- `ProotLauncher` passed the token in the OUTER env, but the shell is exec'd through
  `/usr/bin/env -i` which CLEARS it -> token never reached the child. Moved token+socket into
  the inner env (args to env). This is why the token flow was "unproven".
- `openSession`/`closeSession`/`loginShellEnv`/`onSessionExit` were dead: no API opened a PTY.
  Added `SessionApi` (action=open|close|resize) wired to the service; session device/operator
  come from the token, never client args. `onSessionExit` now revokes the token + pushes a
  `session.exit` event.
- `PtySession.close/releaseFd` killed the pid unconditionally, even after reap -> could signal a
  recycled pid. Guarded with `!hasExited`.
- Cosmetic: literal "internal" strings -> BridgeErrorKind.INTERNAL; logcat read-before-waitFor
  deadlock risk -> bounded drain; SessionToken now takes the injected clock.
- Renamed top-level consts to SCREAMING_SNAKE (Kotlin convention; ktlint property-naming) and
  set detekt TopLevelPropertyNaming.constantPattern='[A-Z][A-Z0-9_]*' to agree.

- **Three device-only bugs the JVM tests missed** (all fixed):
  1. AndroidSocketServer.start() never called NativePty.loadLibrary() ->
     UnsatisfiedLinkError on bindListenSocket. The .so had the symbol.
  2. Android LocalSocket raises `IOException("Try again")` on SO_TIMEOUT, NOT
     SocketTimeoutException. Server caught only the latter -> idle conns dropped.
     Also readFully lost partial bytes on the exception (desync). Fixed: recognise
     timeout by message; readFully propagates only when 0 bytes read, else EOFException
     with initCause.

     (and OEMs block BOOT_COMPLETED until first launch). Added app LaunchActivity.

  dirs are empty) -> proot exec unproven, blocked on Layer 2 packaging, not code.
  Proved the whole socket->PTY->reader->credit chain with /system/bin/sh instead
  (PtyRoundTripInstrumentedTest).
- Instrumented tests CANNOT use backtick names with spaces: R8 fails
  "Space characters in SimpleName ... not allowed prior to DEX version 040"
