## Toolchain (this sandbox — reinstalled from scratch)
Container had no JDK/SDK. Installed to the ephemeral root:
`sudo apt-get install -y openjdk-21-jdk-headless unzip curl`, then Android SDK
(cmdline-tools 11076708, platform-34, build-tools 34.0.0, ndk 26.3.11579264,
cmake 3.22.1) into `/opt/android-sdk`. Env for every gradle run:
```
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64
export ANDROID_HOME=/opt/android-sdk
export GRADLE_USER_HOME=/tmp/gradle-home
echo "sdk.dir=/opt/android-sdk" > local.properties
```
These are ephemeral — reinstall after a container restart.

## libv publishing gotcha
`compileJava` and `compileKotlin` must agree on the JVM target or Gradle rejects
the build ("Inconsistent JVM-target compatibility"). Set **both** to 17:
`kotlin.compilerOptions.jvmTarget = JVM_17` **and** `java.sourceCompatibility/
targetCompatibility = VERSION_17`.

## Lint gotchas that cost time
- **ktlint's `MaxLineLength` is 100**, and `@Suppress("X") // reason` inline pushes
  past it. Worse, ktlint rejects a line comment between a KDoc and an `@Suppress`.
  The accepted shape is a bare `@Suppress("SwallowedException")` on its own line
  directly above the declaration, with the reason folded into the KDoc above.
- **A multi-line `catch (\n @Suppress(...)\n e: T,\n)` gets mangled**: ktlint
  reorders it to `Exception: e`. Suppress at **function** level instead.
- detekt `SwallowedException` is silenced by the function-level `@Suppress`; it
  does not accept the annotation on the catch parameter cleanly here.
- detekt `MagicNumber` wants named constants for `0xFFFF`, `0xFF`, PEM width 64,
  code length 8, error-body preview 256, payload sizes 4.
- `@OptIn(ExperimentalSerializationApi::class)` is needed on the `Json { ... }`
  builder (explicitNulls).

## Gradle gotchas
- `local.properties` must exist with `sdk.dir` or the build cannot find the SDK.
- Tests live in `tests/cloud-connector/unit/kotlin`; the module's `sourceSets.test`
  points there.
- `:cloud-connector` depends on `:android-core` (`api(project(...))`) because it
  feeds the PTY broker and the bridge.
